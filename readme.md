# 📘 Smart Study Schedule

Smart Study Schedule is a simple and interactive web-based study planner that helps students organize their daily routine, track study and coding hours, and manage revision schedules efficiently.

---

## 🚀 Features

- Add and view daily study routines  
- Built-in study and coding timer  
- Tracks total study and coding hours  
- Schedule and manage revision topics  
- Clean and easy-to-use interface  

---

## 🛠️ Technologies Used

- HTML  
- CSS  
- JavaScript  

---

---

## ▶️ How to Run

1. Download or clone the repository  
2. Open `index.html` in any web browser  
3. Start adding routines, tracking time, and scheduling revisions  

---

## 🎯 Project Aim

To help students manage their study time effectively, stay consistent, and improve productivity using a simple digital schedule.
